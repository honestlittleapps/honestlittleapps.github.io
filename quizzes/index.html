How importing works

  • Kahoot!: In Kahoot! choose Create → Add question → Import spreadsheet, then upload this file. Answers and 20-second timers come in ready.
  • Blooket: In Blooket choose Create → CSV Import, give the set a title, then upload this file. If Blooket asks for its own template, paste rows 3 onward into it.
  • Gimkit: In a new Gimkit kit choose Import from Spreadsheet and upload this file. If needed, paste rows 3 onward into Gimkit’s template.
  • Quizlet / Knowt: In Quizlet create a set → Import → paste the file’s contents (between term and definition: Tab; between cards: New line). Knowt accepts the same paste.
  • Flashcard CSV: Two columns (Front, Back). Imports into Brainscape and other flashcard apps that accept a two-column CSV.
  • Anki: Double-click the file (or File → Import in Anki / AnkiMobile). The deck appears with all cards ready to study.
  • Moodle (GIFT): In Moodle open the question bank → Import → GIFT format, and upload this file. Every answer is pre-marked.
  • Microsoft Forms: In Microsoft Forms choose Quick Import → Upload from this device → Quiz. Tick the correct answers from the key on the last page.
