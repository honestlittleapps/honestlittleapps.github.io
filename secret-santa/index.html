How the private links work

The draw happens in your browser. Each person's match is scrambled into their own link (after the # sign), so it's never stored on a server and there's no sign-up or email. Anyone holding a link can open it, so send each link only to its owner.

Questions

How do I draw names for Secret Santa online without emails?
Type the names here, tap Draw names, then send each person their own link by text or WhatsApp. Each link reveals only that person's match.
Can I stop couples from drawing each other?
Yes. Add each pair to the exclusions box, like Ana + Ben. The draw will never match them.
Can the organiser take part too?
Yes. As long as you only open your own link, you'll only see your own match, the same as everyone else.
Is anything saved?
No. The draw happens on your device and the match is scrambled into each link. There's no account and no server storage.
