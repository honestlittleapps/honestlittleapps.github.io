Set it up

  1. Zoom: Settings → Background & Effects → Virtual Backgrounds → + → Add Image.
  2. Microsoft Teams: in a meeting, More → Video effects → Backgrounds → Add new (or Upload on the pre-join screen).
  3. Google Meet: click Apply visual effects (the sparkle icon) → Backgrounds → + Upload a background image.
  4. FaceTime & webcams on Mac: use your camera app's background option if it has one; otherwise it works as a desktop wallpaper too.
