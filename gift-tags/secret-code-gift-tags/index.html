Secret Code Gift Tags

Type your name and it turns into a little puzzle on every tag: a number code, a letter shift or a backwards name. They solve it to learn who the gift is from.

Codes used: number code (A=1, B=2…), letter shift (each letter moved forward one, so they shift it back) and backwards spelling. The hint is printed on each tag.

Tip: print on white card stock at 100% scale, cut around each tag and punch the circle for ribbon.

Questions

How do I print these gift tags?

Type the names (optional), tap Print, and choose 100% or Actual size. Card stock works best. You can also download the blank PDF and write names by hand.

What size are the tags?

Each tag is about 2.5 × 2.4 inches, twelve to a US Letter sheet. On A4 paper, choose “Fit to page”.

Can I use them for a church, school or fundraiser?

Yes, they're free for personal, classroom, church and nonprofit use. Please don't resell them.
