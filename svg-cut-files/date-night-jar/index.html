Date Night Jar SVG

A clean, ready-to-cut design for jar labels, gift kits, couples' crafts. Every letter is already converted to a cut path, so it works without installing any font. Free, no sign-up, no email.

Download SVG

How to cut it

  1. Cricut Design Space: New Project → Upload → Upload Image → choose the SVG → Add to Canvas. Resize, then Make It.
  2. Silhouette Studio: File → Open → choose the SVG (Designer Edition or higher opens SVGs; Basic can use the PNG preview with Trace).
  3. Glowforge or laser cutters: upload the SVG; set the paths to Cut or Engrave.
  4. It's a single colour layer: great for vinyl, HTV and cardstock. Weed the insides of letters like a, e and o.

Free for personal use and small-business products (up to 500 items). Please don't resell or share the file itself. The design is 563×702 units and scales to any size.
